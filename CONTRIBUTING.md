# Contributing

## Commit Guidelines

Use [Conventional Commits](https://www.conventionalcommits.org/):
`<type>(<scope>): <description>`

Types: feat, fix, docs, style, refactor, test, chore, perf, ci, build, security

## PR Workflow

1. Branch from `main`
2. Make commits with conventional messages
3. Open PR with description
4. Wait for review
5. Squash merge

## Code Style

- Java: Spotless Maven plugin
- TypeScript: ESLint + Prettier
- Format on save (`.vscode/settings.json`)
